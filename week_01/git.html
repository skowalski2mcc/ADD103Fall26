Git and GitHub

1. Understanding Git and Github

Git and GitHub are VERSION CONTROL SYSTEMS (VCS). They can be thought of a "save point" for your projects so that you do not have to save it under multiple names or hit "undo" a million times to reach your last working checkpoint.

Git and Github are related, but they ARE NOT the same thing!

Git runs directly on your computer and requires no internet connection. On the other hand, GitHub is a website and hosting service (owned by Microsoft), that hosts your Git repositories online.

2. VS Code Source Control Process

Initialization

  1. I start my initial setup by creating the repository on GitHub and changing the settings to fit my needs (usually just enabling README.md and choosing public/private).
  2. I then need to make sure that my project is connected to the correct account by using the following commands in a terminal:
    • git config --global user.name "[MY NAME]"
    • git config --global user.email "[MY EMAIL]"
    • git config --global --list

Commit Changes

  1. Before anything, I make sure that everything is working as intended and every file is saved!
  2. Once I am ready to commit my changes, I have AI create my commit notes by clicking the "Generate Commit Message" button.
  3. Click the blue "Commit" button.
  4. Click the blue "Publish Branch" button
